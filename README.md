# 烟报自动核对助手

这是按你上传的“手工烟报”模板改的网页工具。当前重点不是普通收入表，而是香烟烟报。

## 当前支持的模板结构

系统会读取每个 sheet 左侧 A-K 的香烟区域：

| 列 | 字段 |
|---|---|
| A | 序号 |
| B | 商品名称 |
| C | 价格 |
| D | 进货 |
| E | 早班库存 |
| F | 早班售卖数量 |
| G | 早班售卖金额 |
| H | 夜班库存 |
| I | 夜班售卖数量 |
| J | 夜班售卖金额 |
| K | 合计金额 |

右侧饮料、小商品区域暂时不作为第一版重点，后续可以继续加。

## 已完成的烟报功能

### 1. 导入整个月手工烟报

直接上传类似：

```text
6月手工烟报.xlsx
```

系统会自动读取每个日期 sheet，并解析香烟明细。

### 2. 每日烟报汇总

自动汇总：

- 每日进货数量
- 早班销量
- 夜班销量
- 当日总销量
- 早班销售金额
- 夜班销售金额
- 当日总金额
- 当日异常数量

### 3. 商品月汇总

按商品名称和价格汇总：

- 月进货
- 早班销量
- 夜班销量
- 月销量
- 月销售金额
- 月末结存

### 4. 交接核对

系统自动检查：

```text
夜班库存 = 早班库存 + 进货 - 早班售卖数量
```

也会检查：

```text
次日早班库存 = 前一日夜班库存 - 前一日夜班售卖数量
```

如果不一致，会进入“交接核对”异常表。

### 5. 金额核对

系统自动检查：

```text
早班售卖金额 = 早班售卖数量 × 价格
夜班售卖金额 = 夜班售卖数量 × 价格
合计金额 = 早班售卖金额 + 夜班售卖金额
```

金额不一致会自动标记异常。

### 6. 每周香烟盘点

系统默认用最新日期的：

```text
夜班结束结存 = 夜班库存 - 夜班售卖数量
```

作为系统库存。你填实盘库存后，自动计算差异，并可导出盘点表。

### 7. 导出 Excel

可以一键导出：

- 每日汇总
- 商品月汇总
- 交接异常
- 原始明细

## 重要限制

当前版本是前端 MVP：

- 数据不会上传服务器；
- 数据只在当前页面临时解析；
- 刷新后需要重新上传 Excel；
- 适合先验证烟报逻辑是否正确。

后续正式使用应该接 Supabase 数据库、登录权限、员工录入、云端保存和备份。
