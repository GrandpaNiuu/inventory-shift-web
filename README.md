# 全球商品经营数据自动核对系统

这是一个面向经营报表、商品库存、工资表、收款表、进货表、费用表、跨境电商商品表等 Excel 文件的网页端自动核对工具。

项目当前采用 **Next.js + TypeScript + SheetJS** 构建，目标不是只处理一种固定表格，也不是只识别香烟和饮料，而是逐步升级为：

```text
任意 Excel 导入
→ 自动识别表格类型
→ 自动识别字段
→ 自动识别商品分类
→ 自动生成核对规则
→ 自动发现异常
→ 自动生成核对报告
→ 对已学习模板和商品词库实现后续自动核对
```

系统目前包含三层能力：

1. **万能表格核对中心**：识别任意 Excel 的字段、类型、规则和异常。
2. **全球商品覆盖中心**：识别各种商品类别，统计商品覆盖率和未识别商品。
3. **商品报表专用模块**：保留当前商品销售、库存交接、自动库存盘点和收款统计逻辑。

## 当前项目定位

### 1. 万能表格核对中心

适用于第一次上传的陌生 Excel 表格。系统会自动分析：

- 工作表 Sheet；
- 表头所在行；
- 字段含义；
- 表格类型；
- 可能的核对规则；
- 明显异常数据；
- 可保存的字段模板。

适合处理：

| 表格类型 | 当前支持能力 |
|---|---|
| 商品库存/销售报表 | 识别商品、数量、价格、金额、库存字段 |
| 工资表 | 识别员工、底薪、出勤、提成、扣款、应发、实发 |
| 进货表 | 识别供应商、商品、数量、单价、金额 |
| 费用表 | 识别日期、费用类型、金额、备注 |
| 收款表 | 识别日期、收款渠道、实收金额、单号 |
| 库存表 | 识别期初、入库、出库、结存 |
| 通用表格 | 检查重复、空值、负数、金额异常等基础问题 |

### 2. 全球商品覆盖中心

适用于任何包含商品名称的表格。系统会自动：

- 识别商品名称列；
- 识别 SKU / 货号 / 条码列；
- 识别价格、数量、金额列；
- 按全球商品词库自动分类；
- 计算商品识别覆盖率；
- 统计各分类商品数量、数量合计和金额合计；
- 输出未识别商品，方便后续补充别名库或商品库；
- 导出全球商品覆盖报告。

### 3. 商品报表专用核对模块

适用于当前门店商品报表，包含更强的固定业务规则：

- 商品销售汇总；

- SKU / 货号 / 条码识别；

## 自动核对规则

系统会根据识别到的字段自动生成基础核对规则。

### 商品/销售类

```text
金额 = 数量 × 单价
```

```text
结存 = 期初/早班库存 + 入库/进货 - 出库/销量
```

### 工资类

```text
实发工资 = 应发工资 - 扣款 - 借支
```

```text
应发工资 = 基本工资 + 奖金 + 提成 + 加班费
```

### 收款类

```text
按收款渠道汇总金额，并检查空值、负数和异常值
```

### 通用类

```text
检查空值、重复记录、负数金额、合计行和数值异常
```

## 当前商品报表专用逻辑

商品报表专用模块当前支持以下规则。

### 1. 自动库存盘点

导入表格后，系统自动生成账面库存盘点结果：

```text
月末账面应剩 = 最新日期夜班库存 - 最新日期夜班销量
```

自动盘点表包含：

- 分类；
- 商品名称；
- 价格；
- 本月进货；
- 早班销量；
- 夜班销量；
- 本月总销量；
- 月末账面应剩；
- 最新日期；
- 异常数；
- 状态。

### 2. 早班交夜班核对

```text
夜班库存 = 早班库存 + 进货 - 早班售卖数量
```

如果夜班库存不符合规则，系统会标记为库存交接异常。

### 3. 次日接班核对

```text
次日早班库存 = 前一日夜班库存 - 前一日夜班售卖数量
```

如果次日早班库存不符合规则，系统会标记为次日接班异常。

### 4. 金额核对

```text
早班售卖金额 = 早班售卖数量 × 价格
夜班售卖金额 = 夜班售卖数量 × 价格
合计金额 = 早班售卖金额 + 夜班售卖金额
```

金额异常只提示，不默认写回原表。

### 5. 收款渠道统计

系统会从 Excel 中动态识别收款渠道，并生成：

- 每日收款明细；
- 收款渠道月统计；
- 全部渠道合计。

## 当前限制

当前版本是前端工具，主要用于快速验证自动核对逻辑。

需要注意：

- 数据不会上传服务器；
- 模板保存在当前浏览器本地；
- 商品分类词库目前是内置基础版，不能覆盖全球所有商品；
- 第一次见到的新商品可能进入未识别清单；
- 未识别商品需要后续补充别名、SKU、条码或分类词库；
- 第一次见到的新业务表格只能自动推断，不能保证 100% 符合真实业务规则；
- 商品报表专用模块准确度高于通用识别；
- 写回原表只会写入明确准备写回的库存修正，金额异常默认只提示。
