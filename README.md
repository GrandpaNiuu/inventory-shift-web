# 库存盘点与早晚班账表合并助手

这是一个面向小店/仓库的在线网页 MVP，用来解决两个核心问题：

1. 每个月把早班账表和晚班账表自动合并成一张月度对账表。
2. 每周生成库存盘点清单，录入实盘数量后自动计算差异并导出盘点表。

> 当前版本优先保证流程跑通。数据暂时保存在浏览器 localStorage，适合先部署成网页测试。后续如果要多人同时使用，需要接 Supabase 数据库。

## 已完成的第一版功能

### 早班/晚班账表

- 支持导入早班表格。
- 支持导入晚班表格。
- 支持手工录入或修正某一天某个班次。
- 同一天同一班次自动覆盖旧记录，避免重复统计。
- 自动计算应收：现金 + 微信 + 支付宝 + 平台收入 - 退款 - 支出。
- 支持实收金额，不填时默认等于应收。

### 月度合并核对

- 按月份自动把早班和晚班合并到每日明细。
- 自动标记：缺早班、缺晚班、早班不平、晚班不平。
- 汇总早班收入、晚班收入、应收合计、实收合计、差异。
- 一键导出 Excel：
  - 月度汇总
  - 每日合并核对
  - 班次明细
  - 异常记录

### 每周库存盘点

- 支持新增商品和批量导入商品库存。
- 一键生成本周 SKU 盘点清单。
- 输入实盘库存后自动计算差异。
- 自动标记正常 / 有差异 / 未盘。
- 一键导出 Excel：
  - 盘点汇总
  - SKU 明细
  - 差异商品

2. 选择 Import Git Repository。
3. 选择这个仓库：`GrandpaNiuu/inventory-shift-web`。

## 后续必须补的生产功能

如果要真正给员工长期使用，不要一直只用 localStorage。下一步应接入：

1. Supabase 登录。
2. Supabase PostgreSQL 数据库存储。
3. 用户权限：老板、管理员、早班员工、晚班员工。
4. 操作日志。
5. 云端数据备份。
6. 手机扫码盘点。
7. OCR 截图识别，但识别结果必须人工确认后再入账。

数据库草案在：

```text
database/schema.sql
```

## 关键业务规则

- 同一天 + 同一班次，只保留一条记录。
- 自动核对依据：应收合计与实收合计是否一致。
- 缺少早班或晚班会进入异常记录。
- 库存盘点确认前不会自动改系统库存。
- 财务和库存数据不能只依赖 OCR 自动识别，必须人工确认。
