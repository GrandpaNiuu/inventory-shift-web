# 万能表格自动核对助手

这是一个面向经营报表、商品库存、工资表、收款表、进货表、费用表等 Excel 文件的网页端自动核对工具。

项目当前采用 **Next.js + TypeScript + SheetJS** 构建，核心目标不是只处理一种固定表格，而是逐步升级为：

```text
任意 Excel 导入
→ 自动识别表格类型
→ 自动识别字段
→ 自动生成核对规则
→ 自动发现异常
→ 自动生成核对报告
→ 对已学习模板实现后续自动核对
```

同时，系统保留了当前已经较完整的 **商品库存/销售报表专用核对逻辑**，用于处理门店商品销售、库存交接、自动库存盘点和收款统计。

---

## 当前项目定位

本项目分为两层能力：

### 1. 通用智能表格核对中心

适用于第一次上传的陌生 Excel 表格。系统会自动分析：

- 工作表 Sheet；
- 表头所在行；
- 字段含义；
- 表格类型；
- 可能的核对规则；
- 明显异常数据；
- 可保存的字段模板。

适合处理：

| 表格类型 | 当前支持能力 |
|---|---|
| 商品库存/销售报表 | 识别商品、数量、价格、金额、库存字段 |
| 工资表 | 识别员工、底薪、出勤、提成、扣款、应发、实发 |
| 进货表 | 识别供应商、商品、数量、单价、金额 |
| 费用表 | 识别日期、费用类型、金额、备注 |
| 收款表 | 识别日期、收款渠道、实收金额、单号 |
| 库存表 | 识别期初、入库、出库、结存 |
| 通用表格 | 检查重复、空值、负数、金额异常等基础问题 |

### 2. 商品报表专用核对模块

适用于当前门店商品报表，包含更强的固定业务规则：

- 商品销售汇总；
- 每日报表汇总；
- 分类销售汇总；
- 自动库存盘点；
- 早班/夜班交接核对；
- 次日接班库存核对；
- 金额核对；
- 收款渠道统计；
- 异常报表导出；
- 已纠正原表导出。

## 当前页面模块

网页目前包含 4 个主入口：

```text
智能上传
商品报表专用
模板库
规则说明
```

### 智能上传

用于上传任意 Excel。系统会自动完成：

- 判断表格更像哪种业务表；
- 识别每一列的业务字段；
- 生成可执行的基础核对规则；
- 发现明显异常；
- 导出智能核对报告；
- 保存识别结果为模板。

### 商品报表专用

保留当前商品报表的专用核对能力，适合处理门店商品销售、库存交接和收款统计。

### 模板库

已识别过的表格可以保存为模板。模板保存在浏览器本地，后续同类表格会优先套用已保存的字段映射。

### 规则说明

说明当前系统边界：

- 已学习过的模板可以接近全自动；
- 第一次见到的新表格会自动推断，但业务规则仍建议确认；
- 商品报表专用模块比通用识别更准确；
- 后续可继续加入可视化规则编辑器。

## 自动核对规则

系统会根据识别到的字段自动生成基础核对规则。

### 商品/销售类

```text
金额 = 数量 × 单价
```

```text
结存 = 期初/早班库存 + 入库/进货 - 出库/销量
```

### 工资类

```text
实发工资 = 应发工资 - 扣款 - 借支
```

```text
应发工资 = 基本工资 + 奖金 + 提成 + 加班费
```

### 收款类

```text
按收款渠道汇总金额，并检查空值、负数和异常值
```

### 通用类

```text
检查空值、重复记录、负数金额、合计行和数值异常
```

## 当前商品报表专用逻辑

商品报表专用模块当前支持以下规则。

### 1. 自动库存盘点

导入表格后，系统自动生成账面库存盘点结果：

```text
月末账面应剩 = 最新日期夜班库存 - 最新日期夜班销量
```

自动盘点表包含：

- 分类；
- 商品名称；
- 价格；
- 本月进货；
- 早班销量；
- 夜班销量；
- 本月总销量；
- 月末账面应剩；
- 最新日期；
- 异常数；
- 状态。

### 2. 早班交夜班核对

```text
夜班库存 = 早班库存 + 进货 - 早班售卖数量
```

如果夜班库存不符合规则，系统会标记为库存交接异常。

### 3. 次日接班核对

```text
次日早班库存 = 前一日夜班库存 - 前一日夜班售卖数量
```

如果次日早班库存不符合规则，系统会标记为次日接班异常。

### 4. 金额核对

```text
早班售卖金额 = 早班售卖数量 × 价格
夜班售卖金额 = 夜班售卖数量 × 价格
合计金额 = 早班售卖金额 + 夜班售卖金额
```

金额异常只提示，不默认写回原表。

### 5. 收款渠道统计

系统会从 Excel 中动态识别收款渠道，并生成：

- 每日收款明细；
- 收款渠道月统计；
- 全部渠道合计。

### 6. 分类规则

当前默认保留两个主要分类：

- 香烟(酒店库存)；
- 饮料。

其中饮料分类已合并包含：

- 饮料；
- 打火机；
- 火机；
- 方便面；
- 泡面；
- 螺蛳粉；
- 零食；
- 杂项；
- 小商品；
- 日用品等。

## 当前限制

当前版本是前端工具，主要用于快速验证自动核对逻辑。

需要注意：

- 数据不会上传服务器；
- 模板保存在当前浏览器本地；
- 换浏览器或清理缓存可能丢失模板；
- 第一次见到的新表格只能自动推断，不能保证 100% 符合真实业务规则；
- 商品报表专用模块准确度高于通用识别；
- 写回原表只会写入明确准备写回的库存修正，金额异常默认只提示。
